## NinjaGo Café : The Crossroads

The CAD model of a project with my friends. We designed a new product for LEGO as part of the Hult Challenge: A pop-up NinjaGo café called The Crossroads. My friends worked on the business model, menu, and target audience research, while I was in charge of the CAD model.

The final cafe design (decorations and wall art added on procreate)

### Features

The model include:

- Full 3D interior model of the café
- Ninjago / LEGO-inspired furniture, decorations and colour scheme
- Customer seating / eating areas
- Merchandise store corner
- Movie corner with beanbags
- Coffee prep area, kitchen, and cashier counter for the staff

### Accessing the Model

The original CAD model was created using Onshape.

1) Open the Onshape document using the link below
2) Sign in to your Onshape account
3) You can view and explore the model here
4) To make your own edits, create a copy of the document (under the Onshape document menu)

### [Link for the OnShape document](https://cad.onshape.com/documents/fa278f244e35182da032a076/w/c41262520424de34fd11e9f5/e/fe3a7fe2305d7edb33ce1960?renderMode=0&uiState=6b004a966204d01120fa8ec9)

### Editing the Files Locally

If you would like to work with the CAD model using another local CAD software:

1) Download the model from Onshape in a supported format (such as STEP (.step/.stp))
2) Open your CAD software
3) Import the downloaded file into the software
4) Make any modifications or additions to the model
